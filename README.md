# Nihal Barcin Portfolio

Static portfolio website for GitHub Pages.

## Before publishing
In `index.html`, replace:
- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN_URL`

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `portfolio`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose **main** and **/(root)**.
6. Save.

Your site will be available at:
`https://YOUR_GITHUB_USERNAME.github.io/portfolio/`

## Custom domain
After buying `nihalbarcin.com`, open:
**Repository → Settings → Pages → Custom domain**
and enter `nihalbarcin.com`.
Then configure your domain registrar DNS for GitHub Pages.
